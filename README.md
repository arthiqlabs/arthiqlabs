# ArthIQ Labs

Human intent, meets AI-native execution.

ArthIQ Labs is an AI platforms company. We build AI-native platforms for hard
problems: fields where the rules are strict, the math is hard and a wrong
answer costs trust.

### Platform 01: Jyotish (live)

A deterministic engine computes the astronomy, checked against NASA JPL
Horizons; AI writes only on top of computed, cited results.

- **[Vedaksha](https://vedaksha.net)**: clean-room astronomical ephemeris and Vedic
  computation engine in Rust, for Rust, Python, WebAssembly and MCP.
- **[KundaliMCP](https://kundalimcp.com)**: Vedic astrology computation for AI agents
  over the Model Context Protocol, every inference cited to its classical source.
- **[kundali.live](https://kundali.live)**: consumer Jyotish in seven languages.
- **[JanamPatri](https://janampatri.net)**: a marketplace for live readings with
  verified Jyotishis, plus free kundali, matching and panchang tools.
